راهنمای کاربر
برای کاربران سطح client_viewer و client_admin — راهنمای ورود، آشنایی با داشبورد، تحلیل‌ها، گزارش‌گیری و تغییر رمز عبور
۱۱ بخش · از ورود تا رفع مشکلات
✎
راهنمای مدیر کلاینت
مکمل راهنمای کاربر برای سطح client_admin — ویرایش پروفایل، مدیریت کلیدواژه‌ها، کانال‌های رسمی، وعده‌ها و بروزرسانی داده‌ها
۸ بخش · ابزارهای مدیریت پروفایل
⚙
راهنمای مدیر سیستم
راهنمای کامل برای سطح super_admin — مدیریت کاربران، پروفایل‌ها، منابع داده، متغیرهای عمومی، ثبت رویدادها و عملیات روزمره
۱۲ بخش · مدیریت کلی سامانه
درباره این راهنماها هر سطح دسترسی، فرض می‌کند که شما با سطوح پایین‌تر آشنایی پایه دارید. مدیر سیستم بهتر است ابتدا راهنمای کاربر و سپس راهنمای مدیر کلاینت را مرور کند تا با تجربه کاربر نهایی آشنا باشد.
